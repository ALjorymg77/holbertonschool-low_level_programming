# Functions and nested loops

0-putchar.c: Prints _putchar followed by a newline.
1-alphabet.c: Defines a function that prints the lowercase alphabet.
2-print_alphabet_x10.c: Prints the lowercase alphabet ten times.
3-islower.c: Checks whether a character is lowercase.
4-isalpha.c: Checks whether a character is an alphabetic letter.
5-sign.c: Prints the sign of a number and returns its sign value.
6-abs.c: Computes the absolute value of an integer.
7-print_last_digit.c: Prints and returns the last digit of an integer.
8-24_hours.c: Prints every minute from 00:00 to 23:59.
9-times_table.c: Prints the multiplication table from 0 to 9.
10-add.c: Adds two integers and returns their sum.
11-print_to_98.c: Prints integers from a starting number to 98.
